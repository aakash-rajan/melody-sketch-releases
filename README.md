# Melody Sketch

A melody sketchpad by Aakash: one sine voice, custom pitch collections, editable bends, rhythm controls, and WAV/MIDI export.

[Website and playable browser instrument](https://melody-sketch.aakashrajan.chatgpt.site)

## Download status

The browser instrument is playable. Native macOS AU/VST3/standalone and Windows x64 VST3/standalone builds are in preparation. No public native installer has been released yet. Only install assets published under this repository's Releases page and linked from the website.

## Support

[Report a bug or ask a question](https://github.com/aakash-rajan/melody-sketch-releases/issues/new/choose). Include your version, system, browser or DAW, and steps to reproduce the problem. Reports are public: do not attach private projects, credentials, or personal data.

MIDI receivers need a pitch-bend range of ±24 semitones. WAV is the option for preserving the exact sine melody; it excludes the click, backing loop and DAW effects.

This repository holds release information and support only. It does not publish the native source code.
